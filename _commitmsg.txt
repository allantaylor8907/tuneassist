The TUI is the default and primary interface. The classic Rich wizard + its
render adapter added a second interactive surface to maintain for little gain:
headless use is covered by --json (stable contract) and --batch (plain report),
and the TUI covers interactive.

- Remove wizard.py, render.py, test_wizard.py (~700 lines).

  (cli.run), which still serves SSH / scripts / terminals the TUI can't draw in.
- test_garage imported the garage codec via wizard's back-compat re-exports;
  point it at core directly.
- Docs (README, CLAUDE) updated to reflect TUI + --batch/--json only.
